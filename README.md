# KTscan and KTprint releases

This repository publishes signed installers only. It does not contain source code.

Installed KTscan and KTprint services read the latest release once a day. Each release contains:

- `KTscan-Client.msi`
- `KTscan-Server.msi`
- `KTscan-Server-NoDriver.msi`
- `KTprint-Client.msi`
- `KTprint-Server.msi`
- `manifest.json`, with the product version, the `stable` channel, and the SHA-256 of each MSI

The source code lives in a separate repository.
